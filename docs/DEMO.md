# 4-minute demo script

1. Open the Learning room and show the sample course. Explain that the demo timeline stands in for a real video until a video URL is entered and **Load video** is clicked. YouTube links and direct MP4/WebM links are supported.
2. At `00:05`, ask “What is reciprocal rank fusion?” Show the future-content refusal and that no future transcript citation appears.
3. Move the timeline to `13:10` and ask “What does hybrid retrieval combine?” Show the timestamp citation and click it to seek.
4. Use **Simplify**, **Compare concepts**, **Summarize so far**, and **Quiz me**; point out that each request uses a small time-filtered set of resources.
5. Upload a PDF or PPTX and ask a question answered only by it. Show the page/slide citation.
6. Open Mock interview. Paste a short sample profile and role description. Answer a project question; show that the follow-up refers to the prior answer.
7. Complete the practice and show the dimension-by-dimension scorecard, evidence language, and cost estimate.
8. Finish on `/docs`, architecture, deployment target and the evaluation CSV. State that API keys/cloud credentials are configured by the team.

Before recording, upload an authentic course video/transcript pair and check that each timestamp aligns. Do not present the illustrative sample transcript as a real lecture transcript.


For your own lesson, paste its YouTube URL and click **Load video**. Wait for **Transcript ready**; the course title changes to the video's title automatically. Play the video, then ask for a summary. No manual VTT/SRT download is needed for videos with available captions. If YouTube blocks caption access or captions are unavailable, the UI shows the reason and prevents use of unrelated sample notes. The mock-mode banner remains visible until a real model provider is configured.
